# حاسبة البلوت — تطبيق iOS أصلي (Native Swift & SwiftUI)

تطبيق iOS أصلي بالكامل بلغة **Swift 6** وواجهات **SwiftUI** لحساب نقاط البلوت والتحكيم مع دعم كامل للغة العربية (RTL) والإنجليزية (LTR)، ويعمل **محلياً 100% دون الحاجة إلى إنترنت أو سيرفر**.

---

## 📱 المميزات المنفذة (مطابقة للمواصفات المتفق عليها)

1. **الأسماء الافتراضية والتخصيص:**
   - العربية: `لنا / لهم` | الإنجليزية: `Us / Them`.
   - إمكانية تعديل وتغيير اسم أي فريق في أي وقت من خلال الضغط على اسمه في كارت النتيجة.
   - عند تبديل اللغة، لا تتم ترجمة الأسماء المخصصة من قبل المستخدم.

2. **تسجيل الأيدي والقواعد الحسابية:**
   - قبول الأرقام الإنجليزية (`123`) والأرقام العربية الشرقية (`١٢٣`).
   - رفض الأرقام السالبة، الكسور، والنصوص.
   - **الصفر التلقائي:** عند إدخال نقاط لفريق وترك خانة الفريق الآخر فارغة، تُعتبر تلقائياً `0`.
   - منع تسجيل يد تحتوي على صفر للفريقين معاً (`0 - 0`).

3. **لوحة الأرقام المدمجة وتوزيع النقاط المباشر (Direct Allocation):**
   - لوحة أرقام iOS مدمجة تحت خانات التسجيل مع زر تفعيل/إلغاء سريع (ON/OFF) ومن الإعدادات.
   - أزرار اختصارات سريعة لنقاط البلوت الشائعة (`+8`، `+16`، `+26`).
   - زرّان عريضان للفريقين: `[ + لنا ]` و `[ + لهم ]`. بمجرد كتابة الرقم والضغط على اسم الفريق، تُسجل النقاط له مباشرة ويأخذ الفريق الآخر `0`.

4. **نهاية المباراة وحساب المتبقي:**
   - الهدف الافتراضي `152` نقطة مع إمكانية تغييره قبل بدء المباراة.
   - الفريق الذي يصل للهدف أو يتجاوزه يفوز؛ وفي حال وصول الفريقين معاً يفوز صاحب المجموع الأعلى.
   - في حال التعادل عند الهدف يستمر اللعب حتى كسر التعادل.
   - إيقاف استقبال أيدي جديدة فور إعلان الفائز.

5. **سجل الأيدي والتصحيحات الذكية (Undo / Edit / Delete):**
   - التراجع عن اليد الأخيرة (`Undo`).
   - تعديل أو حذف أي يد سابقة مع إعادة احتساب المجاميع تراكمياً.
   - في حال أدى التعديل إلى فوز مبكر في يد سابقة، يقوم التطبيق بتنبيه المستخدم وعرض الأيدي اللاحقة لحذفها بتأكيد صريح (`ConflictModal`).

6. **الحفظ المحلي (100% Offline):**
   - حفظ تلقائي للمباراة الجارية والمباريات المؤرشفة داخل ذاكرة الجهاز بملف JSON محمي بآلية الكتابة الذرية (Atomic Writes).
   - استعادة المباراة بعد إغلاق التطبيق دون الحاجة لاتصال بالإنترنت.

## 🛠 هيكل المشروع (Clean Architecture)

```text
baloot-ios-native/
├── Package.swift                    # حزمة SwiftPM الرسمية (تُفتح في Xcode مباشرة أو على Linux)
├── xtool.yml                        # إعدادات البناء المباشر عبر xtool لنظام Linux / WSL
├── Baloot.xcodeproj/                # مشروع Xcode جاهز للبناء والتشغيل والتصدير
├── Assets.xcassets/                 # أيقونة التطبيق الرسمية عالية الدقة (1024x1024)
├── Resources/
│   ├── AppIcon.png                  # أيقونة التطبيق الأصلية
│   └── Info.plist                   # إعدادات الحزمة واللغات المدعومة
├── Sources/
│   ├── BalootCore/                  # منطق الأعمال والحسابات (Pure Swift - Cross-Platform)
│   │   ├── Models.swift             # النماذج (Match, Hand, TeamID, MatchStatus)
│   │   ├── Scoring.swift            # حساب المجاميع وشروط الفوز
│   │   ├── Validation.swift         # التحقق من الأرقام ودعم الأرقام العربية
│   │   ├── KeypadAllocation.swift   # منطق التوزيع المباشر للوحة الأرقام
│   │   ├── MatchEngine.swift        # محرك المباراة، التراجع، الأرشفة، والتعارضات
│   │   └── MatchStorage.swift       # الحفظ المحلي الآمن في ملفات الجهاز
│   └── Baloot/                      # واجهات المستخدم (SwiftUI)
│       ├── BalootApp.swift          # نقطة انطلاق التطبيق والمظهر العام
│       ├── AppState.swift           # إدارة الحالة باستخدام مسار Observation الحديث (iOS 17+)
│       ├── ContentView.swift        # الشاشة الرئيسية والتنقل
│       ├── ScoreBoardView.swift     # كروت النقاط وشريط التقدم وتعديل الأسماء
│       ├── HandInputView.swift      # إدخال النقاط ولوحة الأرقام المدمجة
│       ├── HandHistoryView.swift    # سجل الأيدي والأزرار المنبثقة للتعديل والحذف
│       ├── Sheets.swift             # النوافذ المنبثقة (الإعدادات، مباراة جديدة، المباريات السابقة)
│       └── L10n.swift               # الترجمة الكاملة (عربي RTL / إنجليزي LTR)
├── Tests/
│   └── BalootCoreTests/             # 29 اختبار آلي شامل (نجحت جميعها 100%)
├── build-ubuntu.sh                  # سكربت تشغيل الاختبارات والبناء على نظام Ubuntu / WSL
└── .github/workflows/
    └── build-ios.yml                # بناء تلقائي مجاني لملف IPA عبر GitHub Actions
```

## 🧪 تشغيل الاختبارات الآلية (Linux / WSL)

يمكنك تشغيل الاختبارات داخل بيئة **Ubuntu** لديك في أي وقت بالأمر:
```bash
cd baloot-ios-native
./build-ubuntu.sh
```
النتيجة:
```text
Test Suite 'All tests' passed.
Executed 29 tests, with 0 failures (0 unexpected) in 0.12 seconds.
```

## 📲 خيارات تثبيت التطبيق على جهاز الآيفون الخاص بك

### الخيار 1: البناء التلقائي لملف IPA عبر GitHub Actions (بدون الحاجة لجهاز ماك)
1. ارفع مجلد `baloot-ios-native` إلى مستودع في حسابك على GitHub.
2. سيعمل ملف العمل (`.github/workflows/build-ios.yml`) تلقائياً على خوادم macOS مجانية من GitHub، وسيقوم ببناء ملف `Baloot.ipa`.
3. قم بتحميل ملف `Baloot.ipa` من صفحة الـ Actions.
4. وصّل الآيفون بالكمبيوتر عبر كابل USB واستخدم أداة **Sideloadly** أو **AltStore** لتثبيته مباشرة على جوالك بحساب Apple ID المجاني الخاص بك.

### الخيار 2: الفتح والبناء عبر Xcode (إذا توفر جهاز Mac)
1. افتح مجلد المشروع في Xcode مباشرة عبر ملف `Baloot.xcodeproj` أو `Package.swift`.
2. اختر جهاز الآيفون الخاص بك الموصول بالكيبل كـ Target.
3. اضغط **Run (Cmd + R)** ليتم تثبيت التطبيق وتشغيله فوراً على هاتفك.
